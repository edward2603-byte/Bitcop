# Первый локальный запуск WorkControl

Эта инструкция предназначена для проверки на одном компьютере. Подключать другие компьютеры пока нельзя.

## Перед запуском

1. Используйте Windows 11 либо редакцию Windows 10 LTSC/Enterprise, которая указана Microsoft как поддерживаемая для .NET 10.
2. Установите [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) версии `10.0.404` или более новый патч ветки `10.0.4xx`.
3. Установите [Node.js LTS](https://nodejs.org/) версии 20 или новее.
4. Перезагрузите компьютер или повторно войдите в Windows после установки.
5. Скачайте репозиторий и распакуйте его в обычную локальную папку.

## Запуск

1. Дважды щёлкните `manager.bat` в корне папки проекта.
2. При первом запуске дождитесь загрузки компонентов. Откроются два служебных окна и браузер.
3. В браузере должен открыться адрес `http://127.0.0.1:5173`.
4. Проверьте зелёную надпись «Источник: локальный API».
5. Откройте папку `release`, затем `agent`, и запустите `employee.bat`.
6. В окне агента оставьте адрес `http://localhost:5080` и нажмите «Отправить контрольное событие».
7. Вернитесь в браузер и нажмите «Обновить».

## Ожидаемый результат

- в таблице появились имя пользователя Windows и имя этого компьютера;
- статус компьютера — «На связи»;
- активность — «Активен», «Неактивен» или «Длительное отсутствие»;
- время последней связи заполнено;
- жёлтой надписи «ДЕМОНСТРАЦИОННЫЕ ДАННЫЕ» нет.

## Если запуск не удался

- Сообщение про .NET: установите именно **.NET 10 SDK**, а не только Runtime.
- Сообщение про Node.js: установите Node.js LTS 20+ вместе с npm.
- Жёлтое предупреждение в браузере: API не запущен; проверьте окно `WorkControl API - локально`.
- Агент сообщает «Нет связи»: проверьте адрес `http://localhost:5080` и окно API. Событие останется в локальной очереди и будет отправлено после восстановления.

Для остановки закройте окно агента и оба служебных окна WorkControl. Скрипт не требует прав администратора и не открывает сетевой порт.
