# Индекс модулей

| Код | Модуль | Статус | Публичная ответственность |
| --- | --- | --- | --- |
| M01 | Organization | реализован минимум | Организации, группы, сотрудники |
| M02 | Identity | задел | Пользователи, роли, доступ |
| M03 | Devices | реализован минимум | Регистрация и последняя связь устройств |
| M04 | Telemetry | реализован минимум | Приём, валидация и дедупликация событий |
| M05 | Activity | технический минимум | Состояние active/idle, исходный простой и признак длительного отсутствия |
| M06 | TimeAccounting | запланирован | Показатели рабочего дня |
| M07 | Applications | запланирован | Учёт программ и окон |
| M08 | Productivity | запланирован | Настраиваемая классификация |
| M09 | Reports | техническая сводка | Локальное отображение полученных событий; бизнес-отчёты и экспорт не реализованы |
| M10 | Audit | запланирован | Журнал действий администратора |

Контракты первой итерации расположены в `src/server/WorkControl.Api/Contracts`. Модули не должны использовать внутренние таблицы соседнего модуля.

Платформа локального прототипа: .NET 10 LTS; версии SDK и пакетов закреплены в `global.json` и файлах проектов. Переход выполнен в TASK-003A без изменения ответственности модулей.
