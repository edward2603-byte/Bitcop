# Индекс модулей

| Код | Модуль | Статус | Публичная ответственность |
| --- | --- | --- | --- |
| M01 | Organization | минимальный | Организации, группы, сотрудники |
| M02 | Identity | реализован для пилота | AppUser GUID, три роли, cookie, CSRF, group scope, bootstrap ADMIN |
| M03 | Devices | реализован для пилота | Enrollment, Pending/Active/Suspended/Revoked, одобрение, отзыв |
| M04 | Telemetry | реализован для пилота | Аутентифицированный приём, валидация, дедупликация |
| M05 | Activity | технический минимум | active/idle, исходный простой, длительное отсутствие |
| M06 | TimeAccounting | запланирован | Утверждённые показатели рабочего дня не реализованы |
| M07 | Applications | запланирован | Учёт программ не реализован |
| M08 | Productivity | запланирован | Классификация не реализована |
| M09 | Reports | техническая сводка | Защищённое отображение принятых событий без демо-fallback |
| M10 | Audit | минимальный | Вход/выход и административные решения без секретов |

Публичные контракты находятся в `src/server/WorkControl.Api/Contracts`. Browser и agent используют разные схемы аутентификации. Модули не должны принимать DeviceId или права группы из недоверенного тела запроса.

Платформа: .NET 10 LTS, React/Vite, Windows WPF. Запрещённые без отдельной задачи области: снимки экрана, клавиатура, сайты, поисковые запросы, содержимое документов и автоматическая оценка сотрудников.
