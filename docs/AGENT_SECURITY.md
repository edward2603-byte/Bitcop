# Секреты и жизненный цикл Windows-агента

- Одноразовый enrollment-код создаётся ADMIN, хранится на сервере как SHA-256 и действует 10 минут.
- При первом применении код помечается использованным; повтор отклоняется.
- Выданный 256-битный secret показывается только в ответе enrollment. Сервер хранит только SHA-256.
- Агент шифрует secret через Windows DPAPI `CurrentUser` в `%LOCALAPPDATA%\WorkControl\agent-credential.bin`.
- `agent-settings.json` содержит только URL, AgentId, DeviceId и KeyId. SQLite-очередь содержит события, но не secret.
- Нельзя копировать DPAPI-файл между пользователями/ПК, помещать его в Git, резервную копию общего доступа или журнал.
- Ротация создаёт новый KeyId/secret и немедленно отзывает предыдущий. Новый secret должен быть сохранён DPAPI до следующей отправки.
- Отзыв устройства переводит его в `Revoked` и отзывает все credentials. Для возврата требуется решение ADMIN и новый enrollment; старый secret не восстанавливается.
- Агент не отключает проверку TLS. Сетевой HTTP отклоняется; HTTP допустим только для localhost LOCAL.

При потере/повреждении DPAPI-файла: отозвать устройство в панели, удалить локальный credential-файл и выполнить новый enrollment. Не пытаться получить исходный secret из серверной базы — его там нет.
