# Журнал архитектурных решений

## ADR-001 Modular monolith

Сервер остаётся единым ASP.NET Core приложением. Причина: одна организация, до 100 устройств и необходимость простого локального развёртывания. Микросервисы и Kubernetes не используются.

## ADR-002 PostgreSQL и SQLite

PostgreSQL хранит серверные сущности и первичные события. SQLite используется только агентом как локальный буфер на случай отсутствия сети. Агент удаляет запись из буфера только после успешного ответа API.

## ADR-003 Идемпотентные события

Каждое событие имеет GUID `eventId`; сервер устанавливает уникальный индекс. Повторная доставка возвращает успешный ответ с `duplicate=true`.

## ADR-004 Интерфейс отчётов

В первой версии применена знакомая сотрудникам структура: боковая навигация, период, фильтры и табличная сводка с индикаторами времени. Визуальные материалы — только референс взаимодействия; продукт создаётся независимо.

## ADR-005 Границы первой итерации

Нет сбора скриншотов, веб-истории, поисковых запросов и содержимого ввода. Любое расширение потребует отдельной задачи, политики обработки данных и согласования.
