# TASK-002 Подготовка к первому локальному испытанию

## Цель

Подтвердить безопасный локальный запуск и полную цепочку «агент — API — SQLite — панель» без разработки новых бизнес-модулей.

## Затронутые части

M03 Devices, M04 Telemetry, технический минимум M05 Activity, техническая сводка M09 Reports, Windows-агент, веб-интерфейс и сценарий локального запуска.

## Реализуемое поведение

- запуск из чистой копии при установленных .NET 8 SDK и Node.js 20+;
- API и панель слушают только loopback-интерфейс;
- тестовый пакет агента создаётся установленным SDK;
- события сохраняются в SQLite, дубликаты не создаются;
- очередь агента переживает отсутствие API и отправляется после восстановления;
- неактивность наступает с 60 секунд, длительное отсутствие — с 300 секунд;
- длительность простоя, активность и подключение остаются независимыми данными;
- недействующие разделы интерфейса отключены, демонстрационные строки явно отмечены.

## Ограничения

Нет аутентификации агентов, авторизации пользователей и HTTPS. До `TASK-003` сетевой пилот с реальными данными запрещён. Запрос объяснения длительного отсутствия не реализуется.

## Проверка

- сборка API, агента и веб-интерфейса;
- автоматические тесты API, агента и React-интерфейса;
- создание пакета `release/agent`;
- ручной сквозной тест по `FIRST_RUN_CHECKLIST.md`.

## Результат проверки 24.11.2026

- API и Windows-агент собраны в Release без предупреждений и ошибок.
- Выполнено 10 .NET-тестов: 10 успешно, 0 пропущено.
- Выполнено 3 теста React-интерфейса: 3 успешно; production-сборка Vite создана.
- Тестовый пакет агента содержит `WorkControl.Agent.dll` и `employee.bat`.
- Запущенные API и Vite отвечали на `127.0.0.1:5080` и `127.0.0.1:5173`; внешних слушателей не было.
- В работающий API переданы регистрация и событие; повторная передача отмечена как дубликат, сводка вернула «На связи» и «Неактивен».
- Проверена ветка отсутствия зависимостей `manager.bat`: показана русская инструкция, код завершения — 1.

Не отмечены как проверенные: ручной запуск WPF-окна через `employee.bat` и полный запуск `manager.bat` двойным щелчком на чистой пользовательской машине с системными .NET/Node.js. Их необходимо выполнить по `FIRST_RUN_CHECKLIST.md` при технической приёмке.
