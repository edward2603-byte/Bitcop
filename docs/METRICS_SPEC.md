# Спецификация метрик

На этом этапе сервер хранит только контрольные события, поэтому показатели на главном экране являются вымышленными демонстрационными значениями. Они не рассчитываются из телеметрии и не должны использоваться для оценки сотрудников.

После утверждения регламента M06 должен определить:

- начало и окончание дня: первая и последняя подтверждённая активность;
- активное/неактивное время: объединение интервалов без пересечений;
- норму, переработку, опоздания и ранние уходы по согласованному графику;
- отсутствие данных отдельно от нулевой активности;
- правила округления, часовой пояс и обработку перезагрузок.

Все будущие проценты обязаны быть трассируемы до исходных интервалов и явно отображать период и норму.
