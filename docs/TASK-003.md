# TASK-003 Аутентификация, авторизация и HTTPS

## Статус

Подготовлено как следующая отдельная задача. Реализация не начата.

## Цель

Создать минимально безопасную основу для сетевого пилота WorkControl.

## Обязательная область

- аутентификация агентов с отдельными отзывными учётными данными;
- авторизация пользователей панели и разграничение ролей;
- HTTPS для API и панели, отказ от открытого HTTP;
- безопасная выдача, хранение и ротация секретов вне Git;
- аудит входов, отказов и административных действий;
- тесты неавторизованного доступа, подмены агента и отзыва доступа;
- явная процедура включения и остановки сетевого пилота.

## Условие начала

Только отдельное задание после технической приёмки `TASK-002`. До завершения этой задачи реальные данные по сети не передаются.
