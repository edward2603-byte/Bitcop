# Архитектура WorkControl

## Граница системы

Система рассчитана на одну организацию и до 100 компьютеров в локальной сети. Интернет не нужен для основных функций. Она даёт руководителю факты об активности и не является автоматическим доказательством качества работы или дисциплинарного нарушения.

## Компоненты

```text
WPF-агент (Windows) -> REST API (ASP.NET Core) -> SQLite / PostgreSQL
     SQLite-буфер                                  ^
                                                    |
React/Vite веб-интерфейс ---------------------------+
```

Сервер является modular monolith: развертывается как одно приложение, но делится на изолированные функциональные модули. На текущем этапе активны Organization, Devices, Telemetry и базовое Activity. TimeAccounting, Applications, Productivity, Reports и Audit только зарезервированы в индексе модулей.

## Сквозной сценарий первой итерации

1. Агент получает или хранит свой стабильный `agentId`.
2. Он отправляет `POST /api/devices/register` с именем компьютера и именем текущей учётной записи Windows. Если такой сотрудник ещё не зарегистрирован, сервер создаёт первоначальную карточку в рабочей группе.
3. При запуске и далее каждые 30 секунд он определяет время без пользовательского ввода через Windows API `GetLastInputInfo`, помещает в локальный SQLite-буфер событие `activity.status` и отправляет его на `POST /api/telemetry/events`. Передаются только состояние (`active` / `idle`) и число секунд простоя.
4. Telemetry проверяет обязательные поля и уникальность `eventId`, сохраняет событие, а Devices обновляет время последней связи.
5. Веб-интерфейс читает `GET /api/dashboard` и показывает сотрудника, устройство, статус, последнюю связь и последнее известное состояние активности.

Идемпотентность обеспечивается уникальным индексом `AgentEvents.EventId`: повторная отправка не увеличивает учёт.

Для опытной эксплуатации API по умолчанию использует локальный SQLite-файл `workcontrol.db`: он не требует установки PostgreSQL. Подключение PostgreSQL остаётся предусмотренным для последующего развёртывания.
