# TASK-001 Активность и неактивность

## Цель

Передавать базовое состояние компьютера: активен или неактивен, без сбора содержимого ввода, экранов или сайтов.

## Затронутые модули

M04 Telemetry, M05 Activity, M09 Reports, Windows-агент.

## Поведение

Агент раз в 30 секунд определяет продолжительность отсутствия пользовательского ввода через Windows API `GetLastInputInfo`. При простое пять минут или больше отправляется `idle`, иначе `active`. Событие содержит только тип состояния и число секунд простоя. Сервер сохраняет событие и показывает последнее известное состояние в сводке. Для текущего дня сводка также складывает интервалы между регулярными сигналами и показывает «Наблюдаемо» и «Активное». Разрыв между сигналами более 90 секунд не засчитывается, поэтому отключение компьютера не превращается в рабочее время.

## Ограничения

Не собираются нажатия клавиш, текст, содержимое окон, скриншоты, сайты и поисковые запросы. «Наблюдаемо» и «Активное» — техническая оценка по регулярным сигналам, а не табель и не автоматическое решение о дисциплине.

## Проверка

- сборка агента и API;
- агент формирует корректное состояние для заданного простоя;
- API принимает событие `activity.status`;
- веб-интерфейс отображает последнее состояние.
