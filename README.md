# WorkControl

WorkControl — самостоятельная корпоративная система учёта рабочего времени. Это стартовая итерация: она содержит модульный сервер, Windows-агент и русскоязычную панель руководителя.

В проекте реализована первая сквозная цепочка: регистрация устройства, приём событий, индикатор «на связи», состояние активности и расчёт наблюдаемого/активного времени за текущий день. Агент раз в 30 секунд передаёт только состояние «активен» или «неактивен» и длительность простоя; не передаются нажатия клавиш, текст, снимки экрана, сайты или содержимое документов. Скриншоты, веб-активность, блокировки и иные расширенные функции сознательно не включены.

## Состав

- `src/server/WorkControl.Api` — ASP.NET Core API и модули Organization, Devices, Telemetry.
- `src/agent/WorkControl.Agent` — WPF-агент с локальным SQLite-буфером, сигналом связи и состоянием активности.
- `src/web` — React/Vite интерфейс с демонстрационной сводкой.
- `tests/WorkControl.Api.Tests` — модульные тесты контракта события.
- `docs` — требования, решения и инструкции.

## Запуск двойным щелчком

В корне проекта находится один BAT-файл для руководителя.

- `manager.bat` запускается на компьютере руководителя и поднимает сервер на порту 5080, локальную SQLite-базу и панель в браузере. При первом запуске он запрашивает права администратора только для создания правила брандмауэра Windows, чтобы опытные компьютеры могли подключаться по сети. PostgreSQL для опытной проверки не требуется.
- В папку `release/agent` создаётся чистый пакет агента в формате `.dll` без `.exe`; его `employee.bat` копируется вместе с остальными файлами на контролируемый компьютер. На опытном компьютере должен быть установлен .NET 8 Desktop Runtime. При первом запуске агента укажите сетевой адрес сервера, например `http://192.168.1.20:5080`; адрес сохранится для этого пользователя Windows.

## Локальный запуск для разработки

Для опытного запуска `manager.bat` использует локальную SQLite-базу. В проекте уже находится переносимый .NET SDK в `.tools`; отдельно устанавливать SDK не нужно. Для разработки веб-панели требуется Node.js 20+.

1. Запустите `manager.bat` двойным щелчком и подтвердите запрос Windows на права администратора.
2. На контролируемом компьютере скопируйте целиком папку `release/agent` и запустите в ней `employee.bat`.
3. В окне агента укажите адрес API компьютера руководителя, например `http://192.168.0.85:5080`, и нажмите кнопку отправки.
4. В панели руководителя появятся имя учётной записи Windows, компьютер, время последней связи, статус «На связи» и текущая активность.
